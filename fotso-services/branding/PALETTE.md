# Palette officielle FOTSO COMPANY

Adoptée le 17 juin 2026. Remplace définitivement la palette Claude Orange.

## Couleurs principales

| Rôle | Hex | Description |
|---|---|---|
| **Background dark** | `#0a2540` | Bleu marine profond, institutionnel, sérieux. Fond principal. |
| **Background deepest** | `#06182e` | Variante dégradé pour effet de profondeur. |
| **Accent primaire** | `#facc15` | Jaune doré électrique. Signal, audit, alerte qualité. |
| **Accent lumineux** | `#fde047` | Jaune lumineux pour highlights (point d'arrivée courbe, glow). |
| **Texte clair** | `#e8e6e0` | Crème os, contraste doux sur fond foncé. |
| **Texte secondaire** | `#a8b8ce` | Gris-bleu clair pour tagline / metadata. |
| **Grille / structure** | `#13304a` | Bleu marine clair, séparateurs subtils. |
| **Axes / borders** | `#1f4870` | Pour les lignes structurelles plus marquées. |

## Pourquoi cette palette

- **Bleu profond** = quant institutionnel sérieux. Distinctif des palettes IA (Anthropic, OpenAI, Google) qui dominent l'orange/violet.
- **Jaune doré électrique** = honore le parcours réel du président (génie électrique). Signal lumineux d'audit/alerte. Pas du jaune taxi cru.
- **Crème os** = chaleur humaine sur fond froid, évite l'effet "corporate distant".
