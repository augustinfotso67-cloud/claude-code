## ✏️ ÉTAPE 1 — Remplir tes contacts (2 min)

Ouvre `index.html` dans un éditeur de texte (Bloc-notes suffit) et remplace :

| À chercher | À remplacer par |
|---|---|
| `VOTRE_NUMERO` | Ton numéro WhatsApp au format international **sans + ni espaces** (ex. `237699112233`) |
| `VOTRE_EMAIL` | Ton email pro (ex. `augustin.fotso.quant@gmail.com`) |

Le lien WhatsApp final ressemblera à : `https://wa.me/237699112233`

## 📧 ÉTAPE 2 — Créer un email pro (10 min)

Tu n'as pas encore d'email pro. Option la plus simple et gratuite :

1. Crée un Gmail dédié, genre **`augustin.fotso.quant@gmail.com`** ou **`fotso.audit@gmail.com`**
2. Évite ton email perso (séparation pro/perso = sérieux)
3. Plus tard (Phase 2), tu pourras avoir `augustin@fotso.company` avec un nom de domaine (~10$/an)

---

## 🌐 ÉTAPE 3 — Déployer en ligne avec GitHub Pages (gratuit)

La page est dans le repo `claude-code` sous `fotso-services/`. Pour la publier :

### Option A — Repo dédié (recommandé, plus propre)
1. Crée un **nouveau repo public** sur GitHub : `fotso-audit` (ou le nom que tu veux)
2. Upload uniquement le `index.html` (renomme-le `index.html` à la racine)
3. Settings → Pages → Source : branche `main`, dossier `/root` → Save
4. Ton site sera en ligne sur : `https://augustinfotso67-cloud.github.io/fotso-audit/`

### Option B — Tester en local d'abord (0 déploiement)
Double-clic sur `index.html` → s'ouvre dans ton navigateur. Tu vois exactement le rendu final avant de publier.

> 💡 Commence par l'**Option B** pour valider le rendu, puis **Option A** pour la mettre en ligne quand tu es prêt.
